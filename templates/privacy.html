Privacy Policy

Effective date: October 17, 2026  ·  Last updated: October 17, 2026

Coursework project — no personal data collected

1. Overview

EssayMind is an AI-powered essay evaluation tool built as an academic coursework project by Carl Adrian Baldonado (2CPE-A). This Privacy Policy explains how EssayMind handles information when you use the application at its hosted URL on Render.com.

Short version: EssayMind does not collect, store, or share any personally identifiable information (PII) such as your name, email address, or account credentials. No registration is required to use the application.

2. What Data the Application Collects and Why

EssayMind collects only the minimum data necessary to operate its features:

  • Essay text or uploaded files — the essay content you submit (typed text, PDF, DOCX, TXT, or image). This is processed transiently to generate your evaluation and is not permanently stored on EssayMind's servers after the session ends. File uploads are deleted from disk immediately after text extraction.
  • Anonymous session cookie — a randomly generated UUID stored in a browser cookie (essaymind_uid) that identifies your browser session. It contains no personal information and is used solely to separate your evaluation history from other users on the same server instance.
  • Evaluation history (session messages) — a server-side JSON file (data/chat_history.json) stores evaluation results linked to your anonymous session UUID. This may include excerpts of submitted essay text (up to 300 characters as a title preview) and AI-generated feedback. No name, email, or other identifier is stored alongside these records.
  • Score cache — a SHA-256 hash of submitted essay content plus rubric configuration is cached in data/score_cache.json to avoid redundant API calls for identical submissions. The hash is one-way and cannot be reversed to reconstruct your essay.
  • Local browser preferences — your selected theme (dark/light) and rubric weights are saved in your browser's localStorage. This data never leaves your device.

What we do NOT collect: name, email address, phone number, location data, IP address logs, payment information, or any government-issued ID.

3. How Information Is Used, Stored, and Shared

Use: Submitted essay text is sent to the following third-party services to generate the evaluation:

  • Groq API (groq.com) — the primary AI inference provider. Your essay text is transmitted to Groq's servers to produce evaluation feedback. Groq's handling of API request data is governed by Groq's Privacy Policy.
  • ZeroGPT API (zerogpt.com) — used for AI-detection analysis. Up to the first 5,000 characters of your essay may be sent to ZeroGPT. Their data practices are described in ZeroGPT's Privacy Policy. If ZeroGPT is unreachable, a local rule-based engine is used instead — no external transmission occurs in that case.

Storage: Evaluation history is stored in JSON files on Render.com's ephemeral server filesystem. Render may reset this storage when the service restarts or is redeployed. EssayMind does not use a persistent database.

Sharing: EssayMind does not sell, rent, or share your data with any third party beyond the API calls described above. No analytics trackers, advertising networks, or social media plugins are embedded in this application.

4. Requesting Deletion of Your Information

Because EssayMind does not collect personal information tied to your identity, there is no account to delete. Your evaluation history is associated only with an anonymous browser cookie UUID.

  • Delete individual sessions — you can delete any session directly within the application using the delete (trash) button in the sidebar.
  • Clear all your data — clearing your browser cookies and localStorage for this site removes your session UUID and local preferences. Any server-side history linked to that UUID becomes permanently inaccessible (orphaned data is purged on server restart).
  • Contact request — if you believe identifiable information has been inadvertently stored and you wish to request its removal, contact the developer at the address in Section 6.

5. Security Safeguards and Limitations

The following reasonable safeguards are applied:

  • All traffic between your browser and the server is encrypted via HTTPS (TLS), enforced by Render.com's infrastructure.
  • API keys (Groq) are stored as server-side environment variables and are never exposed to the browser or included in HTML/JavaScript responses.
  • Uploaded files are saved to a temporary path, text is extracted, and the file is deleted immediately — uploaded files are never retained.
  • Essay content transmitted to Groq and ZeroGPT is sent over HTTPS.

Material limitations: EssayMind is a coursework project hosted on Render.com's free tier. It does not implement user authentication, rate-limiting per IP, database-level encryption at rest, or formal security auditing. You should not submit confidential, sensitive, or legally privileged documents through this application. Use only fictitious or non-sensitive test essays.
